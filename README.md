# Next.js Project Setup and Basics

This repository contains the setup and basic configurations for a Next.js project.  
It is part of the ALX learning program and is focused on helping learners understand:

- How to initialize a Next.js project using `create-next-app`
- Project structure and routing with Next.js
- Basic usage of components, props, and state
- Setting up Tailwind CSS for styling

This repo will serve as the foundation for building more advanced Next.js applications in future tasks.
